# myoneAI Configuration Directory

This directory stores configuration templates, schemas, and static definitions for the myoneAI (Tamil JARVIS) assistant.

## Environment Variables
The primary configuration is managed via `.env` in the project root. Refer to `.env.example` for all configurable variables:
- AI Provider & Model keys
- STT & TTS provider settings
- Security confirmation levels
- Logging paths & levels
- Web API URLs
